### ✨ Key Improvements & Features in v1.0.0:
- ⚡ **Fixed Transfer Progress Lifecycle:** Completely eliminated 98%/99% stuck notifications during image, video, and large file uploads and downloads.
- 📱 **Android Foreground Service Hardening:** Reliable persistent notifications with real-time transfer speeds and direct MediaStore synchronization.
- 🔒 **End-to-End Encryption:** Zero-knowledge client-side encryption for files and folder structures.
- 🚀 **High Performance Core:** Low-latency native Rust MTProto core with concurrent multi-chunk streaming.
- 🖥️ **Full Cross-Platform UI:** Modern responsive dark/light interface across Desktop (Windows, macOS, Linux) and Mobile (Android, iOS).
